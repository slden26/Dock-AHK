# MyDock — Кастомні панелі швидкого запуску для Windows

MyDock — це легка та гнучка утиліта на базі AutoHotkey v2, яка дозволяє створювати необмежену кількість док-панелей для організації ваших ярликів.

## 🚀 Основні можливості

* **Багатопанельність:** Створюйте стільки панелей, скільки вам потрібно, через меню в системному треї.
* **Smart Drop:** Додавайте ярлики просто перетягуванням (Drag-and-Drop). Програма автоматично вставить іконку саме в те місце, куди ви її кинули.
* **Повне налаштування:** Для кожної панелі можна окремо змінити:
  - Розмір іконок.
  - Колір фону та прозорість.
  - Режим автоприховування (з'являється при наведенні миші).
* **Зручне керування:**
  - `Shift + Клік` — швидке видалення ярлика з панелі.
  - Перетягування мишею за будь-яку частину панелі (якщо вона не закріплена).
* **Портативність:** Всі налаштування зберігаються в `config.ini`, а ярлики — у папці `Panels`.

## 🛠 Інсталяція та використання

1. Завантажте останній реліз (`MyDock.exe`).
2. Запустіть файл. У треї (біля годинника) з'явиться іконка програми.
3. Натисніть правою кнопкою миші на іконку в треї, щоб додати нову панель.
4. Просто перетягніть потрібні програми або файли на панель.

## ⌨ Гарячі клавіші

- **Shift + ЛКМ по іконці:** Видалити цей ярлик.
- **Правий клік по панелі:** Відкрити налаштування, закріпити позицію або увімкнути автоприховування.
